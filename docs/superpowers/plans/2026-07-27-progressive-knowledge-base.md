# Progressive Knowledge Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an end-to-end, Git-tracked progressive knowledge workflow covering project initialization and audit, bounded task retrieval, review-gated deposition, iteration documentation, and strict CHANGELOG archival.

**Architecture:** Add a focused `@ai-devflow/knowledge` package for Markdown/YAML parsing, structural audit, layout generation, and deterministic retrieval planning. Keep semantic decisions in a separately configurable `project_lead` Pi expert, while `@ai-devflow/scheduler` owns worktrees, locks, recovery, and state gates; SQLite stores audit evidence and run state but never Markdown bodies.

**Tech Stack:** TypeScript 5.7, Node.js 22+, pnpm 11.15.1 workspaces, Electron 43, React 18, Vitest 2, SQLite (`node:sqlite`), Pi JSONL runtime, `yaml` 2.9.0.

## Global Constraints

- `docs/knowledge` is the only long-term knowledge body source of truth and must contain `context`, `adr`, `feature`, `runbook`, `product`, and `ux` indexes.
- `docs/iterations/<version>` is the iteration document root; every task directory has `index.md`, and tasks with code or knowledge changes have `CHANGELOG.md`.
- `project_lead` owns semantic knowledge governance, has an independent model override, does not implement business code, and may write only `docs/knowledge/**` and `docs/iterations/**`.
- Host-side code validates paths, YAML schema, stable IDs, indexes, references, Git tracking, retrieval budgets, and state gates; Agent prose is never sufficient evidence.
- Every relevant Agent run gets a persisted retrieval manifest generated by the host using index-first L1-L4 disclosure.
- A passing review must include a structured knowledge assessment. `valuable` requires successful deposition and validation before `testing -> in_review`; `none` requires a non-empty reason and evidence.
- A missing knowledge base does not block ordinary task execution, but a `valuable` result pauses for explicit initialization confirmation.
- Iteration archive is legal only after CHANGELOG aggregation and verification and a successful sprint-branch merge.
- SQLite may store IDs, paths, counters, findings, evidence references, and diagnostics, but must not store Markdown bodies, prompts, or copied knowledge content.
- Do not add embeddings, vector search, a background indexer, cross-project sharing, automatic Release Notes, or unconfirmed bulk rewrites.
- Use `yaml` 2.9.0 `parseDocument()` and `Document#toJS()` for frontmatter; do not implement YAML parsing with regular expressions.
- Follow TDD for every behavior-bearing task and commit after each task passes its focused tests.

- [ ] **Step 4: Implement frontmatter parsing with `yaml`**

```ts
import { parseDocument } from 'yaml';
import { isKnowledgeFrontmatter, type KnowledgeFrontmatter } from '@ai-devflow/core';

export function parseKnowledgeMarkdown(path: string, markdown: string): {
  frontmatter: KnowledgeFrontmatter;
  title: string;
  summary: string;
  body: string;
} {
  if (!markdown.startsWith('---\n')) throw new Error(`${path}: missing YAML frontmatter`);
  const close = markdown.indexOf('\n---\n', 4);
  if (close < 0) throw new Error(`${path}: unterminated YAML frontmatter`);
  const yaml = markdown.slice(4, close);
  const doc = parseDocument(yaml, { prettyErrors: true, uniqueKeys: true });
  if (doc.errors.length > 0) throw new Error(`${path}: ${doc.errors[0]!.message}`);
  const value = doc.toJS({ mapAsMap: false });
  if (!isKnowledgeFrontmatter(value)) throw new Error(`${path}: invalid knowledge metadata`);
  const body = markdown.slice(close + 5).trim();
  const title = /^#\s+(.+)$/m.exec(body)?.[1]?.trim() ?? '';
  if (!title) throw new Error(`${path}: missing H1 title`);
  const summary = body.split('\n').map((line) => line.trim()).find((line) => line && !line.startsWith('#')) ?? '';
  return { frontmatter: value, title, summary, body };
}
```

The delimiter search is only Markdown frontmatter boundary detection; all YAML semantics are delegated to `parseDocument()`.

export class KeyedLock {
  private tails = new Map<string, Promise<void>>();

  async run<T>(key: string, action: () => Promise<T>): Promise<T> {
    const previous = this.tails.get(key) ?? Promise.resolve();
    let release!: () => void;
    const gate = new Promise<void>((resolve) => { release = resolve; });
    const tail = previous.then(() => gate);
    this.tails.set(key, tail);
    await previous;
    try {
      return await action();
    } finally {
      release();
      if (this.tails.get(key) === tail) this.tails.delete(key);
    }
  }
}
