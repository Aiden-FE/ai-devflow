# 知识检索（Knowledge Retrieve）

## 何时使用

产品、UX、研发负责人、研发、测试与项目负责人在执行任务前，需要复用项目长期知识时使用本技能。

## 协议

1. **先索引后正文**：从根索引 `docs/knowledge/index.md` 与相关分类索引开始，再按预算下钻正文。
2. **遵循宿主 manifest**：宿主已注入 `HOST KNOWLEDGE MANIFEST`，含候选 ID、路径、置信度与预算上限（文件数、字符数）。只在 manifest 允许范围内读取正文。
3. **记录实际读取**：每次读取正文时记录知识 ID、路径、原因与字符数，供结构化结果 `knowledgeReads` 上报。
4. **下钻需说明原因**：需要继续展开关联文档时，记录下钻理由；不要一次性读取全部候选。
5. **代码优于过期知识**：发现知识与代码实际状态不一致时，以代码与用户要求为更高优先级；将差异记入结构化结果，不在只读检索中改写知识。
6. **不伪造**：未读取的文档不得声称已读；未验证的事实不得写入结论。

## 输出

结构化结果中的 `knowledgeReads` 必须反映真实读取；差异通过宿主 manifest 的 `differences` 或审查结论上报。
