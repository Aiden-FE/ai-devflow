# ux-spec-writing

## When to Use
UX专家被产品专家经 `ai_devflow_consult_ux` 子咨询调用时，产出 UX 规格建议。

## Procedure
1. **交互流程**：关键路径状态流转，主要操作与即时反馈。
2. **视觉/结构要点**：布局栅格、组件层级、信息密度、空/错/载态。
3. **可访问性**：键盘可达顺序、读屏语义、对比度、焦点管理与跳过链接。
4. **响应式**：断点（如 sm/md/lg）、断点下布局与交互差异、触控目标尺寸。

## Pitfalls
- 只给"美观"建议而无可验证的结构约束。
- 忽略空/错/载态等边缘状态。
- 可访问性沦为口号而无键盘/读屏具体要求。
